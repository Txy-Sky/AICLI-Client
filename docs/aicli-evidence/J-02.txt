## 实现

- aicli/tier.rs（新增）：TIER2_SUPPORTED = [OpenCode]，Tier 2 走 Chat Completions（openai）。
- aicli/takeover.rs：
  - 接管：Tier 2 没有路由模式，不经模式控制器。备份 opencode.jsonc 与 opencode.json 两个
    文件名（存在哪个改哪个，都不存在则新建 opencode.json），再用 OpenCode 自己的写入器
    opencode_config::set_provider_with_format 写入一个 id 为 aicli 的提供方：
      npm     = @ai-sdk/openai-compatible
      baseURL = <本地代理地址>/app/opencode/v1
      apiKey  = 本地令牌（aicli-local-…，只对本地代理有效）
      models  = 该客户端所用配置集里可路由的公开模型名
    不写入 sk- 密钥或访问令牌；不改用户的默认模型和其他配置。
  - 还原：逐文件写回备份字节，原本不存在的文件删除，写回后逐字节比对；与 C3-10 共用
    同一套备份（SecretStore）与 aicli_takeover 状态机。
  - 代理保活：已接管的 Tier 2 客户端算作代理的使用者（mode/controller.rs 的
    stop_server_if_unused 增加判断）；应用启动时为 active 的 Tier 2 重新拉起代理并刷新
    写入内容；配置集或目录变化时同样刷新。
- 界面未改：OpenCode 仍在「即将支持」里，没有接管按钮（清单要求真实客户端通过后才提供）。
