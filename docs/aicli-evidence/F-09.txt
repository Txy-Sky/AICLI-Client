实现
后端（只写本机 SQLite，不碰 new-api）
1. 表 aicli_privacy_event（CREATE TABLE IF NOT EXISTS，SCHEMA_VERSION 不变）：时间、本地日期、客户端、线路、
   结果（masked / degraded / blocked / media_passed）、原因、个数、不同值个数、类别计数 JSON、占位符
   SHA-256 前 16 位十六进制（只用于跨请求去重计数，每行最多 200 个）。不存原值，也不存占位符本身。
   保留 30 天（写入时最多每 6 小时清理一次）；加入 SYNC_SKIP_TABLES / SYNC_PRESERVE_TABLES，不参与同步；
   解绑或换账户时随用户数据清空。
2. privacy/events.rs：scan_kinds、category_of（机密 / 个人信息 / 网络与设备 / 自定义）、insert、prune、
   record（spawn_blocking，扫描不占请求路径）、summary、list（按 id 翻页、按类别过滤）、clear。
3. local_auth::matched_app：常量时间逐个比较后返回令牌所属客户端，authenticate 放进请求扩展
   （matches 保留）。privacy_middleware 在遮盖成功、降级、阻断、媒体放行处记录，带客户端与当前线路。
4. PlaceholderEngine：register_known（生产 true，行为不变）与 ephemeral()；预览不登记共享已知值索引。
5. 命令 aicli_privacy_summary / aicli_privacy_events / aicli_privacy_preview（≤64 KiB，catch_unwind）/
   aicli_privacy_clear_events，lib.rs 注册。
前端
6. 侧栏「隐私脱敏」（开启时行尾今天遮盖个数）；AicliPrivacyPage：页头开关；未开启提示与「开启」；
   降级红色提示；英雄卡（总数、不同值、请求数、7/30 天柱状图、按客户端条形、拦截 / 降级 / 媒体放行）；
   类别胶囊筛选；按天分组的记录（时间、客户端 → 线路、类别胶囊、结果、个数、加载更多）；试一试
   （占位符高亮）；隐私设置；页脚保留说明与「清空记录」（须确认）。
7. 隐私设置（开关、失败模式、未扫描媒体、自定义词与规则）从「设置 → 本地路由」原样移到本页
   （AicliPrivacySettings），本地路由保留入口与凭据后端降级提示；首页隐私行「查看」进入本页。
8. i18n：nav.privacy、nav.privacyToday、aicli.privacyPage.*（含 29 个类别名），五种语言。
