二、E-02（占位符与密钥，`aicli/privacy/placeholder.rs`）
- 占位符 `{{KIND_xxxxxxxx}}`：HMAC-SHA256(key, `kind\0value`) 摘要 base32（RFC 4648
  无填充）前 8 位小写；正则 `\{\{[A-Z][A-Z0-9_]*_[a-z2-7]{8}\}\}` 常量发布。
- 密钥 32 字节随机（getrandom），Keychain 账户 `privacy-hmac-key`，hex 文本存取，
  首次生成后固定。
- 值表：内存 HashMap + 插入序队列，上限 200,000（测试可注入小值），满时淘汰最旧一半
  （Magpie `makeRoom` 为 Go map 迭代删除，这里按插入序精确淘汰最旧，行为等价且确定）。
- `tools/magpie_golden/`（Go 开发期工具，不进产物）：固定测试密钥经 `redact.SetKeyPath`
  + `redact.Mask(Secrets,Personal)` 对语料生成占位符 JSON，原值经 `redact.Value` 反查，
  kind 取自占位符自身。语料 `tests/fixtures/privacy/golden_corpus.json`（7 条，避免
  GitHub push protection 的 ghp_/xoxb-/AKIA/sk-ant- 真实密钥形态），golden
  `golden_placeholder.json` 7 条（API_KEY×3、TOKEN、PHONE×2、PASSWORD）。
- Rust 侧测试 5 passed（job Rust item tests E-02-unit）：
  1. golden_placeholders_match_magpie_exactly：固定密钥下 Rust tag 与 Magpie golden
     逐条完全一致（含形态自查）。
  2. placeholder_pattern_shape：正则合法/非法形态。
  3. same_value_same_placeholder_across_restart：同值同占位符；新值表同密钥不变；
     kind 不同则不同。
  4. eviction_drops_oldest_half_and_recovers：满丢最旧一半；淘汰后同值得同占位符并可恢复。
  5. key_is_generated_once_and_persisted：密钥生成一次并持久，跨引擎一致。
